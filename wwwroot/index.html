API Escuela Primaria - Matrículas

API REST construida con ASP.NET Core (C#). Gestiona los estudiantes de una escuela primaria, el personal docente y las matrículas por grado. Los datos se guardan en memoria: al reiniciar la API se pierden.

Formato de las respuestas: JSON. Los errores usan siempre este cuerpo:

{
  "estado": 400,
  "mensaje": "El campo 'nombre' es obligatorio y no puede estar vacío.",
  "fecha": "2026-01-15T10:30:00"
}

Endpoints

GET /api/estudiantes

Recibe: nada. Opcionalmente los query params ?matriculado=true|false y ?grado=2do.

Retorna: 200 con el listado de estudiantes.

curl "http://localhost:5106/api/estudiantes?matriculado=true&grado=2do"

POST /api/estudiantes

Recibe (JSON):

{
  "nombre": "Juan Pérez",
  "edad": 9,
  "fechaNacimiento": "2017-05-20",
  "sexo": "M",
  "alergias": "Ninguna",
  "promedio": 4.1,
  "grado": "4to",
  "seccion": "B"
}

Retorna:

  • 400 si falta nombre, edad o grado.
  • 422 si la edad no está entre 5 y 12, si la fecha de nacimiento es futura, si el promedio no está entre 0.0 y 5.0 o si el sexo no es M, F o X.
  • 201 con el estudiante creado (incluye el id generado y la ruta).
curl -X POST http://localhost:5106/api/estudiantes -H "Content-Type: application/json" -d '{"nombre":"Juan Pérez","edad":9,"grado":"4to","promedio":4.1}'

GET /api/estudiantes/{id}

Recibe: el id en la ruta. Retorna: 200 con el estudiante o 404 si el id no existe.

curl http://localhost:5106/api/estudiantes/1
curl http://localhost:5106/api/estudiantes/99

GET /api/estudiantes/{id}/expediente

Recibe: encabezado Authorization: Bearer <rol> (obligatorio).

Retorna: 401 si no viene el encabezado, 404 si el id no existe, o 200 con el expediente académico del estudiante.

curl -H "Authorization: Bearer Docente" http://localhost:5106/api/estudiantes/1/expediente

DELETE /api/estudiantes/{id}

Recibe: encabezado Authorization: Bearer <rol> (obligatorio).

Retorna: 401 sin encabezado, 403 si el rol no es Docente, Director o Admin, 404 si el id no existe, o 204 sin cuerpo si se dio de baja al estudiante.

curl -X DELETE -H "Authorization: Bearer Docente"   http://localhost:5106/api/estudiantes/4
curl -X DELETE -H "Authorization: Bearer Estudiante" http://localhost:5106/api/estudiantes/4

GET /api/estudiantes/{id}/promedio

Recibe: el id en la ruta. Retorna: 500, porque internamente hace una división entre cero (fallo no controlado a propósito).

curl http://localhost:5106/api/estudiantes/1/promedio

GET /api/docentes

Recibe: nada. Opcionalmente el query param ?rol=Docente. Retorna: 200 con el listado del personal docente.

curl http://localhost:5106/api/docentes

POST /api/docentes

Recibe (JSON):

{
  "codigo": "DOC-003",
  "nombre": "Laura Gómez",
  "edad": 34,
  "email": "laura.gomez@colegio.com",
  "rol": "Docente"
}

Retorna:

  • 400 si falta codigo, nombre o edad.
  • 409 si el codigo ya existe (es único).
  • 422 si la edad es menor a 21 o el email no tiene formato válido.
  • 201 con el docente creado.
curl -X POST http://localhost:5106/api/docentes -H "Content-Type: application/json" -d '{"codigo":"DOC-003","nombre":"Laura Gómez","edad":34,"email":"laura.gomez@colegio.com"}'

GET /api/matriculas

Recibe: nada. Retorna: 200 con el listado de matrículas.

curl http://localhost:5106/api/matriculas

POST /api/matriculas

Recibe (JSON):

{
  "estudianteId": 3,
  "codigoDocente": "DOC-001",
  "grado": "1ro",
  "seccion": "A",
  "fecha": "2026-01-20"
}

Retorna:

  • 400 si falta estudianteId, codigoDocente o grado.
  • 404 si el estudiante o el docente no existen.
  • 409 si el estudiante ya está matriculado.
  • 422 si la fecha de matrícula es futura o el docente es menor de 21 años.
  • 201 con la matrícula creada (incluye el id y la ruta del nuevo recurso).
curl -X POST http://localhost:5106/api/matriculas -H "Content-Type: application/json" -d '{"estudianteId":3,"codigoDocente":"DOC-001","grado":"1ro","seccion":"A"}'

DELETE /api/matriculas/{id}

Recibe: el id de la matrícula. Retorna: 404 si la matrícula no existe o 204 con el cuerpo completamente vacío al anularla.

curl -i -X DELETE http://localhost:5106/api/matriculas/1
